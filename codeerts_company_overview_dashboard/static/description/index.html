What this module does

Company Overview is a free executive dashboard that pulls your whole business onto one screen. It automatically detects which Odoo apps you have installed and shows the right KPIs for each, from sales and spend to receivables, pipeline, workload and cash position.

Install it on its own or alongside any CODEerts dashboard. As you add more apps and dashboards, the overview grows with you, adding tiles and charts for each area, with no configuration. Every figure is read as the logged in user, so access rights always apply.

Frequently asked questions

How do I get a single company overview across all Odoo apps?

Install Company Overview. It is free and automatically shows KPIs and charts for every app you have, from sales and purchasing to accounting, inventory, CRM, project and POS, on one executive screen.

Is the Odoo company overview dashboard really free?

Yes. Company Overview is free and open under LGPL-3. It also installs automatically with any paid CODEerts dashboard, so you always have the cross-app view.

Do I need to configure the Odoo company overview dashboard?

No. Just install it. The dashboard automatically detects which Odoo apps you have and shows the matching KPIs and charts, with no fields to map or settings to fill in. As you install more apps or CODEerts dashboards, new tiles appear on their own.

Does the company overview respect each user's access rights across apps?

Yes. Every tile and chart is read as the logged in user, so figures for sales, spend, receivables, pipeline and workload only reflect the records and companies that user can open. It gives an executive view without exposing data people are not allowed to see.

Can I run the Odoo Company Overview dashboard on Community, or does it need Enterprise?

It works on both. Odoo's core app ships in Community, so the dashboard runs on a standard Community install with no Enterprise subscription. It is maintained for the current major Odoo versions; use the version selector on this page to pick your release.

What happens if I only have a few Odoo apps installed?

It detects what is installed and shows only the KPIs those apps can support, so you do not get an empty accounting panel on a database that has no accounting. Install another app later and the matching KPIs appear on their own.
